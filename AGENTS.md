## Правила работы с репо

### Ветки
```
main        ← продакшн (Vercel деплой), только через PR
develop     ← активная разработка
feature/*   ← новые фичи
fix/*       ← исправления
```

### Запрещено для всех агентов:
- Прямой push в `main` — только через Pull Request
- Коммит файлов: `.env`, `*.key`, `*.pem`, `secrets.json`
- Запуск деплоя без явного ОК от VEGAS
- Изменение `vercel.json` без проверки
- Удаление файлов из `photos/` без бэкапа

### Процесс изменений:
1. Агент предлагает изменение → показывает diff
2. VEGAS говорит "ок" / "поправь вот это"
3. Агент коммитит в `develop` или `feature/*`
4. PR создаётся вручную VEGAS или по команде
